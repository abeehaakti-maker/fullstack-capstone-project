# User Story Template

**Title:**
As a [user role], I want [goal/desire] so that [benefit].

**Acceptance Criteria:**
- Given [context], when [action], then [expected result].
- Given [context], when [action], then [expected result].

**Priority:** [High / Medium / Low]

**Story Points:** [estimate]

**Notes:**
- [Any extra details or dependencies]

---

## Example

**Title:**
As a gift giver, I want to search gifts by category so that I can quickly find a suitable present.

**Acceptance Criteria:**
- Given I am on the main page, when I choose a category, then only gifts in that category are shown.
- Given no gifts match, when I search, then I see a "no results" message.

**Priority:** High

**Story Points:** 3

**Notes:**
- Needs the search API (/api/search).
